# Payday bot

Нагадування в Telegram перед зарплатою. Не щодня: у четвер о 19:00 план на п'ятницю, у неділю о 12:00 нагадування не чіпати гроші, відкладені на борг.

Репозиторій публічний. Стартові суми лежать у `payday_bot/seed.py` і з’являться в `data/state.json` після першого запуску. Цей файл у git не потрапляє. Якщо не хочеш, щоб залишки були в історії GitHub, зроби репозиторій приватним.

Бот не підключається до банку. Він рахує план, ти платиш у застосунку банку і підтверджуєш `/done`.

## Запуск

Токен береться в Telegram у [@BotFather](https://t.me/BotFather), команда `/newbot`.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=123:abc
python -m payday_bot
```

У боті натисни `/start`. Перший, хто це зробить, стає власником. Іншим бот не відповідає.

Подивитись план у терміналі без Telegram:

```bash
python -m payday_bot --preview
```

Процес має працювати постійно, інакше четвер і неділя мовчатимуть. Команди `/plan` і кнопки працюють, коли процес запущений.

## Кнопки

- План. Що гасити з найближчої п'ятниці і скільки лишити на життя.
- Борги. Залишки.
- Готово. Записати, що оплатив саме цей план.
- Лексус. Скільки доларів уже зібрано.

Якщо оплатив не за планом, не тисни Готово. Постав фактичний залишок: `/set ліміт 8000`.

Інше:

- `/saved 90` — купив 90 доларів на Лексус
- `/got 800` — тобі повернули гроші, вони підуть у наступну п'ятницю
- `/rate 45.10` — інший курс

## Як рахує

З п'ятниці $500 за курсом у стані. На життя лишається 11 000 грн. Решта йде в борг, поки він є.

Хата 11 000 грн у першу п'ятницю місяця. У той тиждень на їжу лишається 4 000 грн, не повні 11 000. Батькам 10 000 грн з листопада, у другу п'ятницю місяця, щоб не збігалось із хатою.

Розстрочка приймає або платіж за місяць, або всю суму. Зайве лежить окремо, поки не вистачить на повне закриття. Спочатку мишка, місячні платіжі і кредитний ліміт. Потім цілком телефон, потім цілком екофлоу.

Коли боргів немає, та сама п'ятниця каже, скільки купити доларів на Лексус.


## На домашньому сервері

Бот має крутитись на Dell, не на ноуті. Ноут тоді можна вимикати. Сервер лишається увімкненим.

Поруч із цими файлами створи `.env` (його не комітять):

```bash
cp .env.example .env
```

У `.env` встав токен від BotFather. У чат його не кидай.

```bash
docker compose up -d --build
docker compose logs -f
```

У Telegram відкрий бота і натисни `/start`.
