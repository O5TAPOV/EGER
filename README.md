# Де анкета?

Сайт студентів ВДПУ: відкрите опитування про формат навчання під час тривог і анонімні історії з фото та коротким відео. Привід - слова в.о. ректора в сюжеті Суспільного 23 жовтня 2026 про «більшість за офлайн». Студенти практичних спеціальностей кажуть, що гугл-форма в них була. На інших факультетах про неї не чули. Загальної таблиці досі немає.

## Запуск локально

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
DATA_DIR=./data ADMIN_TOKEN="$(python3 -c 'import secrets; print(secrets.token_hex(24))')" .venv/bin/python app.py
```

Сайт слухає тільки локально, якщо запускати через `flask` чи `python`. Для зовнішнього доступу:

```bash
BEHIND_PROXY=1 DATA_DIR=/var/lib/de-anketa ADMIN_TOKEN="довгий-випадковий" \
  .venv/bin/gunicorn --bind 127.0.0.1:8000 --timeout 180 --workers 2 \
  --access-logfile /dev/null wsgi:app
```

Журнал доступів gunicorn не вмикати. `--access-logfile -` запише IP.

Якщо попереду nginx:

```nginx
access_log off;
error_log /var/log/nginx/de-anketa.error.log crit;
proxy_pass http://127.0.0.1:8000;
proxy_set_header Host $host;
proxy_set_header X-Forwarded-Proto $scheme;
```

`BEHIND_PROXY=1` потрібен, щоб сайт розумів https. Адресу клієнта з `X-Forwarded-For` код не читає і не має почати.

## Сховати допис

```bash
curl -X POST -H "X-Admin-Token: $ADMIN_TOKEN" -F "post_id=123" https://сайт/sluzhba/hide
```

Без правильного токена відповідь 404. IP при цьому все одно немає в базі сайту.


## Де це ставити

Не на робочий сервер, не на університетський і не на домашній комп'ютер. Запит за логами прийде власнику акаунта. Якщо акаунт твій, ховати голоси в базі вже пізно: шукають не рядок у SQLite, а людину в договорі.

Крипта сама по собі нікого не ховає. Монета, куплена з картки на своє ім'я і відправлена хостеру з біржового акаунта, де є паспорт, лишає ланцюжок. Між біржею і хостером має бути свій гаманець, а хостер має брати монету без паспорта на дрібний VPS. Звичайний клас таких контор: Njalla, 1984.is, FlokiNET. Це не реклама і не обіцянка, що вони нікому нічого не віддадуть.

Ще щільніше за звичайний домен - тільки onion, без запису в WHOIS. Тоді сайт відкривається з Tor Browser. Хто хоче звичайне посилання в чат і в редакцію, бере домен у реєстратора, який не світить ім'я.

Друг, який не вчиться і не працює у ВДПУ, має сенс лише якщо він сам згоден бути тим, на кого оформлений акаунт, і розуміє, що лист, якщо буде, прийде йому. Людину, яка не в курсі, в договір не ставлять. Своїх з університету і з роботи туди теж не ставлять.

Панель і SSH не відкривати з кампусу і не з роботи. Домашній провайдер теж бачить захід на панель хостера, тож для входу нормально підходить Tor. На сервері не тримати особистий git і не світити ім'я в історії команд.

Окремо від машини: посилання, кинуте з акаунта, де людина вже сперечалася під своїм ім'ям, прив'язує сайт сильніше за WHOIS. На самому сайті цей репозиторій не згадувати.

## Анонімність, без казок

Код не пише IP, ім'я, пошту і точний час. Фото збирається заново без EXIF. Відео перекодовується, метадані зрізаються. Голос тримається на випадковому ключі в браузері, на сервері лише SHA-256.

Це не ховає людину, якщо:

- на фото обличчя, на відео голос, у тексті прізвище або студентський;
- хостер, nginx або Cloudflare ведуть свій журнал IP;
- домен і VPS оформлені на студента, якого і так шукають.

Хто заходить через Tor Browser, не світить свою адресу хостеру. Ще щільніше - onion, тоді з'єднання до машини локальне:

```
HiddenServiceDir /var/lib/tor/de-anketa/
HiddenServicePort 80 127.0.0.1:8000
```

Власника сервера ця схема не маскує. Оренда, оплата і WHOIS мають бути не на людину, яку вже шукають у чаті вишу. Голосуючих це окремо.

Перевірка: `python3 -m pytest -q`
