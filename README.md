# Де анкета?

Сайт студентів ВДПУ: відкрите опитування про формат навчання під час тривог і анонімні історії з фото та коротким відео. Привід - слова в.о. ректора в сюжеті Суспільного 23 жовтня 2026 про «більшість за офлайн» без опублікованої анкети.

## Запуск локально

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
DATA_DIR=./data ADMIN_TOKEN="$(python3 -c 'import secrets; print(secrets.token_hex(24))')" .venv/bin/python app.py
```

Сайт слухає тільки локально, якщо запускати через `flask` чи `python`. Для зовнішнього доступу:

```bash
BEHIND_PROXY=1 DATA_DIR=/var/lib/de-anketa ADMIN_TOKEN="довгий-випадковий" \
  .venv/bin/gunicorn --bind 127.0.0.1:8000 --timeout 180 --workers 2 \
  --access-logfile /dev/null wsgi:app
```

Журнал доступів gunicorn не вмикати. `--access-logfile -` запише IP.

Якщо попереду nginx:

```nginx
access_log off;
error_log /var/log/nginx/de-anketa.error.log crit;
proxy_pass http://127.0.0.1:8000;
proxy_set_header Host $host;
proxy_set_header X-Forwarded-Proto $scheme;
```

`BEHIND_PROXY=1` потрібен, щоб сайт розумів https. Адресу клієнта з `X-Forwarded-For` код не читає і не має почати.

## Сховати допис

```bash
curl -X POST -H "X-Admin-Token: $ADMIN_TOKEN" -F "post_id=123" https://сайт/sluzhba/hide
```

Без правильного токена відповідь 404. IP при цьому все одно немає в базі сайту.


## Де це не ставити

Не на робочий сервер, не на університетський і не на домашній комп'ютер. Запит за логами прийде власнику акаунта хостера. Якщо акаунт твій, ховати голоси в базі вже пізно.

## Анонімність, без казок

Код не пише IP, ім'я, пошту і точний час. Фото збирається заново без EXIF. Відео перекодовується, метадані зрізаються. Голос тримається на випадковому ключі в браузері, на сервері лише SHA-256.

Це не ховає людину, якщо:

- на фото обличчя, на відео голос, у тексті прізвище або студентський;
- хостер, nginx або Cloudflare ведуть свій журнал IP;
- домен і VPS оформлені на студента, якого і так шукають.

Хто заходить через Tor Browser, не світить свою адресу хостеру. Ще щільніше - onion, тоді з'єднання до машини локальне:

```
HiddenServiceDir /var/lib/tor/de-anketa/
HiddenServicePort 80 127.0.0.1:8000
```

Власника сервера ця схема не маскує. Оренда, оплата і WHOIS мають бути не на студентський квиток, якщо автор сайту не хоче бути публічною особою. Голосуючих це окремо.

Перевірка: `python3 -m pytest -q`
